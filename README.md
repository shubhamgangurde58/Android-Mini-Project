# Android Mini Project

# About the Project

This repository contains an **Android Mini Project** developed using **Java** and **XML** in Android Studio as part of my MCA learning journey. The project is designed to practice Android application development concepts such as Activities, Intents, XML layouts, event handling, and user interaction.

The application includes a simple calculator with basic arithmetic operations and demonstrates navigation between multiple screens using Android Intents.

# Features

*  Home Screen
*  Navigation between Multiple Activities
*  Addition
*  Subtraction
*  Multiplication
*  Division
*  Menu Screen
*  User-Friendly XML Layouts
*  Image Resource Integration
*  Event Handling using Java

# Application Workflow

1. Launch the application.
2. Navigate to the menu screen.
3. Select the required arithmetic operation.
4. Enter the input values.
5. Perform the calculation.
6. View the result instantly.
7. Navigate between screens using Android Intents.

# How to Run

1. Clone this repository.
2. Open the project in **Android Studio**.
3. Allow Gradle to sync the project.
4. Connect an Android device or start an emulator.
5. Build and run the application.
